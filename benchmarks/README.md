# Замер скорости

Из корня исходного проекта после установки:

```sh
python -m pip install .
python benchmarks/benchmark.py
python benchmarks/benchmark.py --size-bytes 1048576 --json
```

Скрипт использует только воспроизводимые синтетические данные и произвольное
64-байтовое состояние Salsa20. По умолчанию размер буфера — 256 KiB.
Перед замером и после каждой серии результаты сравниваются побайтно с
`salsa_crypt_python`. Время включает выделение результата и вызов публичной
функции; подготовка данных, сравнение и вычисление SHA-256 в него не входят.

Для Python выполняются три серии. Для C число вызовов удваивается до достижения
0,2 секунды на калибровочной серии, затем выполняются пять серий с этим числом
вызовов. Итоговая скорость рассчитывается по медиане. JSON также содержит
минимум и максимум длительности, платформу, версию Python, число повторов,
MiB/s и ускорение. Число серий меняют параметры `--python-samples` и
`--native-samples`.

Если необязательное C-расширение не собрано, скрипт сообщает об этом и измеряет
только Python. При проверке сборки `build_ext --inplace` без установки используйте
из корня проекта `python -m benchmarks.benchmark --json`.

Это замер вычисления Salsa20 в памяти. Скорость восстановления файлов также
зависит от диска, доли зашифрованных данных и размера файлов. Для сравнения
разных сборок используйте одинаковые параметры и малую фоновую нагрузку.

## Пример результата

На macOS arm64 с CPython 3.14.6, 25 сентября 2026 года, буфер 256 KiB:

| Реализация | Скорость |
| --- | ---: |
| Python | 1,282 MiB/s |
| C | 965,269 MiB/s |

Ускорение вычисления — около 753 раз; результаты совпали побайтно.
Это один локальный замер, а не гарантия скорости на другом компьютере.
