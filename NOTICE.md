# Источники и авторство

Формат метаданных и метод восстановления через повторное использование потока
исследованы [Calif](https://calif.io/research/lockbit-v3) и
[yohanes/lockbit-v3-linux-decryptor](https://github.com/yohanes/lockbit-v3-linux-decryptor).
При разработке использовалось описание реализации из коммита
`062421d89c048fc2493002e03fa0cb7fba4d6c3f`.

Этот проект содержит переносимую реализацию с опорой на опубликованные исследования.
Исходники и бинарники `frank`, библиотека `aplib.a` и другие файлы того репозитория
не включены. Лицензия MIT этого проекта не распространяется на сторонние работы.

Salsa20 разработан Daniel J. Bernstein. Криптографические тесты используют
опубликованный вектор ECRYPT; ссылка на источник указана рядом с вектором.
